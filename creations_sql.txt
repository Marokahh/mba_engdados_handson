Após rodar a extract.py e todas as tabelas foram carregadas no SQL, onde cada microdados de cada ano ficou em uma tabela separada
Vamos juntar em uma tabela compilada, rodando o seguinte código: (Como é a primeira vez, vou criar a tabela)

Importante: usamos UNION ALL, e não UNION.

Como cada tabela representa um ano diferente, não queremos que o PostgreSQL tente eliminar registros "duplicados". Queremos simplesmente empilhar os cinco anos.


CREATE TABLE dw_enem.microdados_enem_compilado_5_anos AS

SELECT *
FROM stg_enem.microdados_enem_2019

UNION ALL

SELECT *
FROM stg_enem.microdados_enem_2020

UNION ALL

SELECT *
FROM stg_enem.microdados_enem_2021

UNION ALL

SELECT *
FROM stg_enem.microdados_enem_2022

UNION ALL

SELECT *
FROM stg_enem.microdados_enem_2023;

2. O que esse SQL está fazendo?

Não estamos alterando os valores das categorias.

Estamos fazendo apenas:

removendo espaços com TRIM();
transformando vazio '' em NULL;
colocando tipos coerentes;
eliminando as colunas que você marcou como N.

E, como combinamos, não estamos colocando notas, respostas, gabaritos, redação etc. nessa tabela, porque você marcou essas variáveis como N.
